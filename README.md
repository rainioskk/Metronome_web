# 在线节拍器

`Online Metronome` 是一款为乐器练习、视唱练耳和节奏训练设计的轻量在线节拍器。打开网页即可使用，无需注册、下载或加载外部音频文件；节拍由 Web Audio API 实时合成，播放时还可以自动保持屏幕常亮。

## 节拍器的用途

- **建立稳定速度**：帮助演奏者保持统一速度，减少越弹越快、越练越拖的问题。
- **慢练与提速**：从舒服的速度开始，分阶段提高 BPM，在可控条件下逐步接近原速。
- **训练细分节奏**：通过八分、三连音、附点八分和十六分等细分，练习更精细的时值与律动。
- **感受拍组和重音**：每 2 至 8 拍设置一次重音，适合练习不同拍感与乐句划分。
- **统一速度参照**：可用于乐器练习、视唱、合奏准备等需要稳定时间基准的场景。

## 在线网页版的优点

相比实体节拍器和需要安装的应用，在线版更轻、更快，也更适合随身练习。

- **零安装，跨平台**：电脑、平板和手机打开浏览器即可使用，不占设备空间，也不需要单独安装应用。
- **打开即用**：没有注册流程和启动门槛，适合课间、排练前或临时需要快速校准速度。
- **实时合成节拍音**：使用 Web Audio API 直接生成节拍，不依赖音色包或网络请求，点击开始即可响应。
- **支持 PWA 与离线使用**：首次访问后可在支持的浏览器中安装到主屏幕；之后即使网络不佳，也能像独立应用一样启动。
- **设置自动保存**：速度、细分、重音、音量、主题和语言等偏好保存在本地，下次打开自动恢复。
- **简约实用**：首屏只保留速度、细分、重音、音量和播放控制，减少练习时的干扰。
- **练习场景更友好**：深浅色模式、响应式布局、防休眠和键盘操作都围绕减少练习中断展开。
- **隐私友好**：无需账号，不上传练习数据；设置和偏好只保存在当前浏览器中。

## 核心功能

- 支持 `1-240 BPM`，可通过滑块、直接输入、加减按钮和传统速度标记调整速度。
- 实时显示 `Larghissimo` 至 `Prestissimo` 的速度术语、中文含义和推荐 BPM，点击即可快速跳转。
- 支持四分、八分、附点八分（摇摆）、三连音和十六分细分，选项带有音符图示。
- 可每 `2-8` 拍强调一次重音，节拍指示灯会与音频同步闪动并高亮重拍。
- 使用 Web Audio API 合成短促、清晰的机械节拍音，并提供独立音量控制。
- 支持简体中文、繁体中文、英语、日语和西班牙语，界面可即时切换。
- 支持浅色、深色主题，初次打开会跟随系统外观，手动选择后记住当前偏好。
- 支持桌面、平板和手机，布局会随屏幕尺寸自动调整。

## 防休眠

“防休眠”用于在练习时保持屏幕常亮，避免设备进入锁屏状态后打断节拍。

- 点击“开始”后自动启用，暂停节拍时自动释放。
- 顶部开关可以随时开启或关闭，状态会显示为待机、启用中、常亮中、不支持或受限。
- 优先使用浏览器原生 Screen Wake Lock API。
- 在 iOS Safari、iPadOS 和 WebApp 模式下，自动降级为一段静音内联视频来保持屏幕活跃。
- 即使浏览器完全不支持防休眠，节拍器本身仍可正常播放。

浏览器通常会要求先通过用户点击“开始”或按空格键来解锁音频。这也是防休眠功能需要从用户手势开始的原因。

## 快捷操作

- `空格`：开始或暂停节拍。
- `↑` / `↓`：将速度增加或减少 `1 BPM`。
- `Shift + ↑` / `Shift + ↓`：将速度增加或减少 `10 BPM`。

## 开发与构建

环境要求：Node.js 和 pnpm。

```bash
pnpm install
pnpm dev
```

生产构建与本地预览：

```bash
pnpm build
pnpm preview
```

构建产物使用相对路径，可部署到任意静态服务器或支持静态托管的平台。

## 技术实现

- 使用 Vite 构建，运行时采用原生 ES Modules，无额外业务依赖。
- 使用 Web Audio API 调度节拍，采用短时前瞻机制减少节拍漂移。
- 使用 Service Worker 和 Web App Manifest 提供 PWA 安装与离线启动能力。
- 使用 `localStorage` 保存用户设置，所有数据均留在本地。
