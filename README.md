# Online Metronome

面向乐器日常练习的轻量在线节拍器。节拍由 Web Audio API 实时合成，不依赖外部音频文件，支持桌面、平板和手机，并可作为 PWA 安装。

## 开发

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 功能

- `1-240 BPM`，支持滑块、步进、预设和 TAP 定速。
- BPM 下方实时显示 `Larghissimo` 至 `Prestissimo` 的传统速度术语。
- 支持 `2/4`、`3/4`、`4/4`、`6/8` 拍号。
- 支持每拍、八分、十六分和三连音细分。
- 使用单一低沉圆润的经典 `dong` 节拍音，并可独立强调第一拍。
- 支持简中、繁中和英文界面动态切换。
- 播放时自动启用 Screen Wake Lock；顶部开关也可随时控制并显示当前状态。
- 支持深浅色模式、设置持久化、响应式布局和离线启动。

## 浏览器说明

音频需要用户点击“开始”、TAP 或按空格键解锁。防休眠依赖 Screen Wake Lock API 与安全上下文；不支持时，按钮会明确显示“不支持”，节拍器本身仍可正常使用。
